Project Name: BPL DREAM-11

Description: 
BPL-DREAM-11 is a fully responsive fantasy cricket web application built using React, Tailwind CSS, and DaisyUI. Inspired by the Dream11 concept, this project allows users to create their ideal cricket team by selecting players under a fixed coin budget.

🛠️ Technologies Used:
1. React JS – JavaScript library for building interactive user interfaces
2. Vite – Fast build tool and development server
3. Tailwind CSS – Utility-first CSS framework for responsive styling
4. DaisyUI – Component library built on Tailwind CSS
5. React Toastify – For showing toast notifications
6. HTML5 & CSS3 – Markup and base styling
7. JavaScript (ES6+) – Modern JS features like arrow functions, destructuring, template literals

⭐ Key Features
1. Team Selection with Budget Control
   Users can select their dream cricket team under a fixed virtual coin limit. Each player has a coin value, making the selection process strategic and fun.

2. Real-Time Feedback & Notifications
   Interactive toast notifications alert users when they add/remove players, exceed the budget, or complete their team — improving user experience.

3. Persistent Data with localStorage
   The selected team and newsletter subscription are saved in the browser using localStorage, so users don't lose progress on refresh.
